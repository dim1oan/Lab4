# Лабораторная работа №4: Чат-бот курсов валют и анализ данных

Проект выполнен в рамках лабораторной работы №4 по дисциплине
«Прикладное программирование» (МГТУ «СТАНКИН», группа ИДБ-25-15).

**Вариант 2:** Курсы валют (актуальные курсы и архив курсов валют).  
**Telegram-бот:** `@currency_2026bot`

## Структура проекта

- `bot.py` — исходный код Telegram-бота на базе `aiogram 3.x`
- `analysis.py` — скрипт анализа архивных данных USD/RUB
- `usd_rub_archive.csv` — архив официального курса USD/RUB ЦБ РФ
- `requirements.txt` — зависимости проекта

## Быстрый старт

```bash
pip install -r requirements.txt
python bot.py
```
