# Лабораторная работа №4: Разработка чат-бота и анализ данных

Проект выполнен в рамках лабораторной работы №4 по дисциплине
«Прикладное программирование» (МГТУ «СТАНКИН», группа ИДБ-25-15, 2 курс).

- **Вариант 2:** Курсы валют (архив курсов валют и актуальные курсы валют)
- **Telegram-бот:** `@currency_2026bot`
- **Репозиторий:** https://github.com/dim1oan/Lab4

## Структура проекта

- `bot.py` — исходный код асинхронного Telegram-бота на базе `aiogram 3.x` и `aiohttp`
- `analysis.py` — скрипт очистки, визуализации и статистического анализа архива USD/RUB
- `usd_rub_archive.csv` — архив официального курса USD/RUB ЦБ РФ (2016–2026 гг., 2 690 записей)
- `usd_rub_dynamics.png` — линейный график динамики курса USD/RUB и 180-дневного скользящего среднего
- `usd_rub_distribution.png` — гистограммы распределения уровня курса и дневных изменений
- `Отчет Лаб 4 Ткачук Д. В. ИДБ-25-15 Прога.docx` — итоговый отчет по лабораторной работе
- `requirements.txt` — список зависимостей

## Возможности Telegram-бота

- `/start` — приветствие и отображение текущей базовой валюты пользователя
- `/rates` (кнопка `📊 Текущий курс`) — актуальные курсы ЦБ РФ относительно базовой валюты с суточным изменением и inline-обновлением
- `/convert` (кнопка `💱 Конвертер`) — конвертер любых валют по кросс-курсу (поддерживает быстрый ввод вида `100 USD RUB`, `50 EUR`, `500 CNY в TRY` и пошаговый FSM-режим)
- `/base` (кнопка `⚙️ Базовая валюта`) — выбор базовой валюты и сохранение настроек в `user_settings.json`
- `/help` — справка по командам и форматам ввода
- Устойчивая обработка исключений (`CurrencyAPIError`, `CurrencyParseError`, `ValidationError`, `SettingsStorageError`, `TelegramBadRequest`)

## Результаты анализа данных (`analysis.py`)

- Период: `01.01.2016 – 26.11.2026` (3 983 календарных дня после заполнения 1 293 выходных/праздничных пропусков методом `ffill()`)
- Средний курс: `73.37 ₽`, медианный: `73.14 ₽`, стандартное отклонение: `11.91 ₽`, минимум: `51.16 ₽` (`30.06.2022`), максимум: `120.38 ₽` (`11.03.2022`)
- **Гипотеза 1 (корреляция со временем):** корреляция Пирсона `r = 0.6983`, Спирмена `0.7316`, `t = 61.56` (`|t| > 1.96`) — подтвержден статистически значимый долгосрочный рост (`+2.64 ₽/год`)
- **Гипотеза 2 (нормальность распределения):** `Skewness = 0.6175`, `Excess Kurtosis = -0.2451`, статистика Жарка–Бера `JB = 263.13` (`> 5.991`) — распределение отличается от нормального

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Добавьте токен бота в локальный файл `.env` (файл исключен из Git через `.gitignore`):
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ```
3. Запустите бота или скрипт анализа данных:
   ```bash
   python bot.py
   python analysis.py
   ```
